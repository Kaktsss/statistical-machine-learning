# Statistical and Machine Learning (SML) & Statistical Programming Languages (SPL)

This repository contains my coursework, R scripts, exercises, and projects for the **Statistical and Machine Learning** and **Statistical Programming Languages** courses (SS26).

## Repository Structure
- `course-materials/` - Weekly folders containing lecture notes, R scripts (`.R`), and R Markdown reports (`.Rmd`).
- `data/` - Datasets used across exercises.

## Tools & Technologies
- **Language:** R / R Markdown
- **IDE:** RStudio / VS Code
- **Key Libraries:** `tidyverse`, `tidymodels`, `glmnet`, `randomForest`
